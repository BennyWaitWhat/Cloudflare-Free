# Security policy

## Supported versions

Only the latest commit on `main` is supported (pre-1.0).

## Reporting a vulnerability

Use **Security > Report a vulnerability** on GitHub, which is private. Please don't open a public issue. You can also use the contact form on a deployed copy; its `/.well-known/security.txt` points there. Expect a reply within 7 days.

## Scope

In scope: the code in `app/` and its Wrangler config. Out of scope: Cloudflare's platform itself; report that at https://www.cloudflare.com/disclosure/.
