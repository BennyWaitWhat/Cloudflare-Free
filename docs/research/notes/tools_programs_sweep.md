# Cloudflare free public tools, free programs, and full-catalog free-offering sweep (as of 2026-10-14)

*Scope: (1) free public tools and APIs, (2) free or sponsored programs, (3) a master checklist of every Cloudflare product with any free allowance (brief rows for areas owned by sibling researchers, depth on uncovered items), (4) cross-cutting rules, (5) the paid-only boundary, (6) 2025-2026 changes. Research was read-only: no Cloudflare resources or accounts were created, changed or deleted.*

*Label legend: FREE-FOREVER = ongoing free allowance; FREE-BETA = free only while in beta, may bill later; TRIAL/CREDITS = time-limited or credit-based; PROGRAM = free only for approved applicants; PAID-ONLY = no free tier; ENTERPRISE-ONLY = sales-led. "(sib)" in a Source cell means the row is condensed from a sibling notes file in this folder (that file cites the primary page; I did not re-fetch it). All other rows were read by me from the cited page on 2026-10-14. Fetch tool output is summarized by a small model, so exact numbers were cross-checked where two sources existed.*

## Free public tools and APIs

### Takeaway
Cloudflare runs roughly a dozen no-cost public tools. The ones an app can call programmatically are the Radar API and URL Scanner API (free Cloudflare account plus a scoped API token), time.cloudflare.com (NTP, NTS) and roughtime.cloudflare.com:2003 (beta), the speed-test endpoints (through the MIT-licensed `@cloudflare/speedtest`), the keyless DoH JSON API at cloudflare-dns.com, the Statuspage JSON API, the per-zone `/cdn-cgi/trace` endpoint (CORS-open on www.cloudflare.com), and the drand randomness beacon. Radar API data is licensed CC BY-NC 4.0 (non-commercial), and none of the pages read publishes service-specific numeric rate limits; the only clearly documented ceiling for authenticated calls is the account-wide Cloudflare API limit of 1,200 requests per 5 minutes per user.

### Cited Findings

#### Cloudflare Radar (website, API, MCP server, datasets) — FREE-FOREVER (account + token), non-commercial data licence
- Radar is a hub for global Internet traffic, attack and technology-trend data, built on Cloudflare's network plus aggregated, anonymized 1.1.1.1 resolver data; the docs list the Radar website, Radar API, Compare data, URL Scanner, Investigate (NetFlows, HTTP requests, DNS queries) and an MCP server. — [Radar docs](https://developers.cloudflare.com/radar/)
- The Radar API gives programmatic access to the same data and is described as free, aimed at academics, technology professionals and web enthusiasts; data available through it is licensed CC BY-NC 4.0 (Creative Commons Attribution-NonCommercial). — [Radar docs](https://developers.cloudflare.com/radar/)
- Auth: send `Authorization: Bearer <token>` using a Custom Token with Account > Radar > Read. The first-request page states no rate limits and no price. — [Radar first request](https://developers.cloudflare.com/radar/get-started/first-request/)
- Documented rate-limit context: the Cloudflare API allows 1,200 requests per 5 minutes per user, cumulative across dashboard, API keys and API tokens, plus a client-API limit of 200 requests per second per IP; exceeding it blocks all API calls for the next 5 minutes with HTTP 429 and a `retry-after` header. That page does not mention Radar or URL Scanner, so any Radar-specific limit is undocumented there. — [Cloudflare API limits](https://developers.cloudflare.com/fundamentals/api/reference/limits/)
- Related Radar items: "Radar Researcher" (AI tool that turns plain-language questions into interactive charts) announced Aug 7, 2026; BEACON, a public BigQuery dataset of anonymized real-user performance measurements from 10,000 major websites, announced Sep 28, 2026. — [Agents Week tag page](https://blog.cloudflare.com/tag/agents-week/), [Birthday Week 2026 wrap-up](https://blog.cloudflare.com/birthday-week-2026-wrap-up/)
- GA/beta: the docs do not label the Radar API as beta; Radar Researcher's release stage is not stated on the listing page. — [Radar docs](https://developers.cloudflare.com/radar/), [Agents Week tag page](https://blog.cloudflare.com/tag/agents-week/)
- Idea: a Worker (holding the read token as a secret) can pull Radar traffic or ranking data for an internal dashboard or a hobby/non-commercial page; a commercial product would need to settle the CC BY-NC question first.

#### URL Scanner (inside Radar) — FREE-FOREVER with account token; price and quotas not published
- API token: Custom Token with Account > URL Scanner > Edit, plus your `account_id`; no price or numeric rate limit or per-period scan quota is stated on the docs page. — [URL Scanner docs](https://developers.cloudflare.com/radar/investigate/url-scanner/)
- Bulk API accepts up to 100 URLs at once; recommended polling interval is 10-30 seconds; successful scans are kept 12 months and failed scans older than 30 days are deleted. — [URL Scanner docs](https://developers.cloudflare.com/radar/investigate/url-scanner/)
- Visibility: Public (default; shown in recent scans and search; default scan takes one desktop screenshot) or Unlisted (excluded from search; reachable only by scan ID; the custom-scan example takes desktop, mobile and tablet screenshots). Scanning from a chosen location is Enterprise-only. — [URL Scanner docs](https://developers.cloudflare.com/radar/investigate/url-scanner/)
- Since May 12, 2026 URL Scanner reports opened from the dashboard include an Agent Readiness tab with six scores (a dashboard feature, not a separate public scanner). — [Changelog 2026-05-12](https://developers.cloudflare.com/changelog/post/2026-05-12-URL-scanner-report-agent-readiness/), [AEO blog](https://blog.cloudflare.com/aeo/)
- Idea: scan user-submitted links in an app's moderation queue using Unlisted scans so the scanned URLs are not published.

#### speed.cloudflare.com and `@cloudflare/speedtest` — FREE-FOREVER, no account
- The site is a browser speed test reporting download, upload, latency, jitter, packet loss and a Network Quality Score; one test can use up to 200 MB; the IP is truncated to /24 (IPv4) or /48 (IPv6) and anonymized results go to measurement partners. — [speed.cloudflare.com](https://speed.cloudflare.com/)
- The measurement engine is the MIT-licensed npm package `@cloudflare/speedtest`; default endpoints are `https://speed.cloudflare.com/__down` and `/__up`, latency uses `__down?bytes=0`, and results are sent to Cloudflare for aggregated insights; default transfers go up to 2.5e8 bytes per request. — [speedtest README](https://github.com/cloudflare/speedtest)
- The public TURN server used for packet-loss testing is deprecated and will be discontinued, so you must supply your own TURN configuration to get packet-loss results; several options (including `authorizationToken`) are marked experimental. The README states no usage terms, rate limits or quotas, and does not say whether embedding on third-party sites is endorsed. — [speedtest README](https://github.com/cloudflare/speedtest)
- Idea: run a quick bandwidth/latency check in the app to pick a lower-quality media rendition, accepting that the endpoint's third-party-use terms are unstated.

#### Time services (time.cloudflare.com NTP and NTS; roughtime.cloudflare.com) — FREE-FOREVER (NTP/NTS), FREE-BETA (Roughtime)
- NTP is offered free over Cloudflare's anycast network; hostname `time.cloudflare.com` with IPs 162.159.200.1, 162.159.200.123, 2606:4700:f1::1 and 2606:4700:f1::123, which are pool.ntp.org members; no rate limits, quotas or SLA stated; setup examples for macOS, Windows, chrony, systemd-timesyncd and ntpd. — [NTP docs](https://developers.cloudflare.com/time-services/ntp/), [NTP usage](https://developers.cloudflare.com/time-services/ntp/usage/)
- Cloudflare does not smear leap seconds; the kernel applies them at the scheduled time (as pool.ntp.org does), and mixing smearing and non-smearing servers can give unpredictable results. — [NTP docs](https://developers.cloudflare.com/time-services/ntp/)
- NTS: clients point at time.cloudflare.com (chrony, NTPsec and ntpd-rs have their own setup docs); the page gives no port and no limits. — [NTS docs](https://developers.cloudflare.com/time-services/nts/)
- Roughtime: `roughtime.cloudflare.com:2003` (IPv4 and IPv6); service is in beta; the root public key may change and can be read from a DNS TXT lookup on roughtime.cloudflare.com; Cloudflare's Go client is `getroughtime` from github.com/cloudflare/roughtime; no rate limits listed. — [Roughtime usage](https://developers.cloudflare.com/time-services/roughtime/usage/)
- Using the time services means accepting the Cloudflare Website and Online Services Terms of Use; no separate SLA, rate-limit or commercial-use text. Docs updated Apr 24, 2026. — [Time services ToS](https://developers.cloudflare.com/time-services/tos/), [Time services overview](https://developers.cloudflare.com/time-services/)
- Idea: a native app can cross-check device time against Roughtime or NTS (for example for licence or token-expiry checks) without any Cloudflare account.

#### Randomness beacon (drand / League of Entropy) — FREE-FOREVER, no account
- Cloudflare's docs page describes drand as a Go daemon whose linked servers jointly produce publicly verifiable, unbiased, unpredictable random values at fixed intervals; it lists no endpoints or limits and defers to drand.love; page updated Apr 24, 2026. — [Randomness Beacon docs](https://developers.cloudflare.com/randomness-beacon/)
- Cloudflare appears in the League of Entropy members list on drand.love, which documents a JSON HTTP API. — [drand HTTP API page](https://drand.love/developer/http-api/)
- Live check on Oct 14, 2026: the public relay `api.drand.sh/v2/chains` returned three chain hashes; the `quicknet` chain (hash beginning 52db9ba7) has a 3-second period, scheme `bls-unchained-g1-rfc9380` and genesis time 1692803367; its latest-round endpoint returned round 33066125, which matches about 2026-10-14 18:15 UTC on that schedule, so the beacon was producing rounds. — [chains](https://api.drand.sh/v2/chains), [quicknet info](https://api.drand.sh/v2/chains/52db9ba70e0cc0f6eaf7803dd07447a1f5477735fd3f661792ba94600c84e971/info), [latest round](https://api.drand.sh/v2/chains/52db9ba70e0cc0f6eaf7803dd07447a1f5477735fd3f661792ba94600c84e971/rounds/latest)
- Idea: pick a future drand round before a giveaway or raffle and derive winners from that round's signature, so the draw is verifiable by users.

#### Privacy Pass and OHTTP — FREE-FOREVER (shared issuer); gateway in closed beta
- Privacy Pass is IETF RFC 9576; Turnstile and Apple Private Access Tokens use it in production; Cloudflare runs shared public RFC 9578 issuer deployments and Workers support redemption natively; no quotas or pricing are stated, no public API a website can call directly is documented, and rate-limiting use cases are still in development. Docs updated Oct 2, 2026. — [Privacy Pass docs](https://developers.cloudflare.com/privacy-pass/)
- Birthday Week 2026 (Oct 2): the self-serve Cloudflare OHTTP Gateway is in closed beta and Privacy Gateway was renamed OHTTP Relay; the OHTTP Relay docs label it Enterprise-only, closed beta, for select privacy-oriented companies. — [Birthday Week 2026 wrap-up](https://blog.cloudflare.com/birthday-week-2026-wrap-up/), [OHTTP Relay docs](https://developers.cloudflare.com/ohttp-relay/)

#### `/cdn-cgi/trace` and other `/cdn-cgi/` paths — FREE-FOREVER, per proxied zone
- Cloudflare adds `/cdn-cgi/` to every domain added to Cloudflare; `/cdn-cgi/trace` reveals the serving data center; the endpoint cannot be modified or customized; sibling paths include `/cdn-cgi/challenge-platform/`, `/cdn-cgi/image/`, `/cdn-cgi/l/email-protection` and `/cdn-cgi/rum` (returns 204); docs advise `Disallow: /cdn-cgi/` in robots.txt (with `Allow: /cdn-cgi/image/` first if you use image transforms). The docs page does not list trace's output fields. — [cdn-cgi docs](https://developers.cloudflare.com/fundamentals/reference/cdn-cgi-endpoint/)
- Live check on Oct 14, 2026 (curl to `https://www.cloudflare.com/cdn-cgi/trace`): HTTP 200, `Content-Type: text/plain`, `Access-Control-Allow-Origin: *`, body fields `fl, h, ip, ts, visit_scheme, uag, colo, sliver, http, loc, tls, sni, warp, gateway, rbi, kex` (colo = data center code, loc = country, warp/gateway/rbi show Cloudflare One state, kex = key exchange group). The response also set a `__cf_bm` cookie. — [live endpoint](https://www.cloudflare.com/cdn-cgi/trace)
- Idea: a site on Cloudflare can fetch its own `/cdn-cgi/trace` for the visitor's country, protocol and WARP state; calling www.cloudflare.com's copy from another origin works today (CORS observed) but is undocumented and carries no SLA.

#### Cloudflare status page API — FREE-FOREVER, no auth
- Public JSON API, no authentication: `/api/v2/summary.json`, `status.json`, `components.json`, `incidents.json` (50 most recent), `incidents/unresolved.json`, `scheduled-maintenances.json` (+ `upcoming.json`, `active.json`); RSS/Atom under `/api/v3/`; no numeric rate limit given, requests without a User-Agent face stricter limiting and an identifiable User-Agent is recommended; no webhook or email subscription is described. — [Status API docs](https://www.cloudflarestatus.com/api)
- Idea: show a "Cloudflare is degraded" banner in the app by polling `summary.json` from a Worker and caching it for a minute.

#### Public DNS-over-HTTPS JSON API (1.1.1.1; owned by the Zero Trust/1.1.1.1 researcher, listed here because an app can call it)
- Endpoint `https://cloudflare-dns.com/dns-query` (also `https://one.one.one.one/dns-query`), GET with `accept: application/dns-json` and `?name=` parameter; no authentication; TLS 1.2 or 1.3; status codes 400, 413, 415, 504 documented; rate limits, usage policy and CORS are not covered on that page. — [DoH JSON API docs](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/)

#### Other no-cost public items found
- Workers AI LLM Playground (playground.ai.cloudflare.com) needs no setup or authentication. — [Workers AI model page](https://developers.cloudflare.com/workers-ai/models/llama-4-scout-17b-16e-instruct/)
- Cloudflare IP ranges are published as a public list (cloudflare.com/ips) and are available through the Cloudflare API; the docs page does not give endpoint details; ranges are said to change infrequently. — [Cloudflare IP addresses](https://developers.cloudflare.com/fundamentals/concepts/cloudflare-ip-addresses/)
- Key Transparency Auditor: Cloudflare audits Logs used for end-to-end-encrypted key distribution and provides an API for anyone to monitor its verification work; pricing not stated; docs updated Oct 2, 2026. — [Key Transparency docs](https://developers.cloudflare.com/key-transparency/)
- Threat Signals and the Threat Events Platform (open-source threat reporting turned into indicators linked to WAF rules) are described as free for every Cloudflare account; the Threat Events Platform expands to all accounts (Sep 29, 2026). — [Birthday Week 2026 wrap-up](https://blog.cloudflare.com/birthday-week-2026-wrap-up/)

### Inferences
- Zero-account services (NTP/NTS, Roughtime, status JSON, DoH JSON, drand relays, speed-test endpoints) are the lowest-friction additions for a website + app; Radar and URL Scanner need only a free account and a scoped token, but Radar's non-commercial licence limits product use.
- Because no per-service rate limit is published for Radar or URL Scanner, an app should assume the account-wide 1,200 requests per 5 minutes per user ceiling and cache results (inference; the limits page does not name these products).

### Gaps
- Radar-specific and URL Scanner-specific rate limits or scan quotas: not found (the dedicated URL Scanner limits page returned 404; the docs search tool returned nothing).
- NTS-KE port, speed-test endpoint usage terms, DoH rate limits and CORS support, and the output-field documentation for `/cdn-cgi/trace`: not stated on the pages read (the trace field list above comes from a live request, not from documentation).
- Whether Cloudflare itself operates api.drand.sh or only participates in the League of Entropy: not established (the drand.love page lists Cloudflare as a member; the docs page lists no endpoints).
- The Cloudflare IP list endpoints (cloudflare.com/ips-v4 and /ips-v6, api.cloudflare.com/client/v4/ips) were not confirmed on the docs page I read.
- A claim in a search summary that the workers.new playground became unauthenticated was not verified on a Cloudflare page.

## Free programs

### Takeaway
Cloudflare's free programs are application-based. Free Business/Enterprise-grade service goes to vulnerable public-interest sites (Galileo), U.S. election sites (Athenian), U.S. federal campaigns, small U.S. school districts (Cybersafe Schools), community ISPs (Pangea) and critical-infrastructure organizations in five countries (Safekeeping). Builders get credits or fee waivers: Cloudflare for Startups ($10k / $100k / $350k credits for one year), a non-profit startup program (up to $250k credits, first cohort of 30 in Oct 2026), Cloudflare for Students (U.S. .edu students, Workers Paid fee waived 12 months, card required), and Project Alexandria (annual credits for open-source projects). Project Fair Shot looks legacy, and the Workers Launchpad is VC-funded rather than Cloudflare-funded.

### Cited Findings

#### Programs for public-interest, civic and infrastructure organizations (PROGRAM)
- **Project Galileo**: for human-rights, civil-society, journalism and democracy organizations with a live, vulnerable public-interest website; apply through a partner sponsor or Cloudflare's contact form; benefits are those of the Business plan (unmetered DDoS mitigation, DNS, SSL, WAF, CDN, cache analytics, Workers, Zero Trust application access, Gateway, image and mobile optimization, PCI compliance); Cloudflare does not disclose participants without permission; no cost or time limit stated. — [Galileo](https://www.cloudflare.com/galileo/)
- Galileo scale and 2026 changes: over 3,500 domains in 120+ countries, applications on pace to more than double year over year, and Galileo participants in news (journalists, independent outlets, nonprofits supporting news-gathering) get free Bot Management and AI Crawl Control; the Birthday Week 2025 recap dates the extension to journalists to Sep 23, 2025. — [Cloudflare Impact $100M post](https://blog.cloudflare.com/100-million-donations/), [Birthday Week 2025 wrap-up](https://blog.cloudflare.com/birthday-week-2025-wrap-up/)
- **Athenian Project**: free for U.S. state, county or municipal government websites for election administration (voting and polling information), voter data (registration or verification) or reporting results; described as enterprise-level protection and performance for free; sign up via the page; no documents or deadlines listed. — [Athenian Project](https://www.cloudflare.com/athenian/)
- Athenian scale: over 440 sites in 33 U.S. states, expanded to election management bodies in eight countries (including Canada, North Macedonia, Georgia and Moldova; expansion date not stated). — [Impact $100M post](https://blog.cloudflare.com/100-million-donations/)
- **Cloudflare for Campaigns**: qualified U.S. federal campaigns get a package free, delivered with the nonprofit Defending Digital Campaigns: WAF, DDoS mitigation, custom blocking rules, load balancing, Zero Trust and Email Security (added in 2025); no formal application flow shown (talk-to-an-expert form); over 530 U.S. websites protected. — [Campaigns](https://www.cloudflare.com/campaigns/), [Impact $100M post](https://blog.cloudflare.com/100-million-donations/)
- **Project Cybersafe Schools**: U.S. public K-12 districts with up to 2,500 students (more than 9,000 districts qualify); free with no time limit: email protection (BEC, phishing, credential-harvesting defense) and DNS filtering (CIPA-compliant); apply through the Cybersafe Schools resource hub; districts that do not qualify can email k-12@cloudflare.com about educational pricing; announced Aug 2023. The cloudflare.com/cybersafe-schools URL now returns 404, so current terms are not confirmed on a live program page. — [Cybersafe Schools update post](https://blog.cloudflare.com/project-cybersafe-schools-update), [Business Wire release](https://www.businesswire.com/news/home/20230808436459/en/Cloudflare-Announces-Project-Cybersafe-Schools-to-Better-Secure-K-12-School-Districts-For-Free)
- **Project Fair Shot** (likely legacy): Waiting Room free for government agencies, hospitals, pharmacies and other organizations facilitating COVID-19 vaccine distribution; no application steps; the only dated item on the page is a 2022 Webby award. — [Fair Shot](https://www.cloudflare.com/fair-shot/)
- **Project Pangea**: free connectivity services for nonprofit or cooperative community networks and small commercial networks primarily providing Internet access to underserved local communities; bandwidth cap 5 Gbps at the 95th percentile (Cloudflare may change it with 15 days' notice); needs backhaul to an eligible Cloudflare peering location; underlying tools are Cloudflare Network Interconnect, Magic Transit and Cloudflare Network Firewall; apply via the page form; may not be available in all jurisdictions. — [Pangea](https://www.cloudflare.com/pangea/)
- **Project Safekeeping** (search-summary of the official page; direct fetch returned 403): free Zero Trust for critical-infrastructure organizations located in Japan, Australia, Germany, Portugal or the United Kingdom, recognized as critical infrastructure by local governments, roughly up to 50 people or under USD 10 million revenue; no time limit; apply via form. — [Safekeeping page](https://www.cloudflare.com/lp/project-safekeeping/), [2022 press release](https://www.cloudflare.com/en-gb/press/press-releases/2022/project-safekeeping-zero-trust-for-critical-infra/)
- Cumulative impact: Galileo, Athenian and related programs have delivered over USD 100 million in donated services (post of Sep 30, 2026); the post says it does not give formal eligibility or cost terms for most programs. — [Impact $100M post](https://blog.cloudflare.com/100-million-donations/)

#### Programs for startups, nonprofits, students and open source (TRIAL/CREDITS or PROGRAM)
- **Cloudflare for Startups** (TRIAL/CREDITS, one year): Tier 3 $10,000 (bootstrapped/self-funded, under $1M raised, Workers AI cap $2,500); Tier 2 $100,000 (under $5M raised, funded by an affiliated partner, Workers AI cap $10,000); Tier 1 $350,000 ($5M+ raised, affiliated partner, Workers AI cap $50,000); R2 covered up to $10,000; credits expire after one year or when used. No-cost inclusions: three Enterprise domains, unlimited Business and Pro plans, DDoS and bot protection, WAF with 1,000 custom rules, SSL, CDN, DNS, Load Balancing (2 origins), Rate Limiting (1 rule). Eligibility: incorporated within 10 years, funded up to Series B with funding in the last 12 months, building a technology product, live public website, active on LinkedIn/X/GitHub, never previously approved, for-profit with company-domain email; consultancies, agencies, MSPs, resellers, educational institutions and personal blogs are not eligible. Not covered by credits: AI Gateway (temporarily), domain registration and renewals, enterprise add-ons, Magic Transit, Enterprise Spectrum, Dedicated IPs, China Network. Review takes up to 48 hours. The page says Tier 3 rose from $5,000 and Tier 1 from $250,000 (undated; members on old limits can ask startups@cloudflare.com for a case-by-case upgrade review that does not extend the 12-month expiry) and contradicts itself on SLA (feature list says 100% SLA, terms say none). — [For Startups](https://www.cloudflare.com/forstartups/)
- Superseded: the April 2025 program had four tiers ($5,000, $25,000, $100,000, $250,000, up to $250,000). — [Developer Week tag page](https://blog.cloudflare.com/tag/developer-week/)
- **Non-profit startup program** (TRIAL/CREDITS): non-profits can receive more than $250,000 in Cloudflare credits plus developer-platform access; the first cohort of 30 organizations was announced the week of the Sep 30, 2026 post (a Spanish-language secondary source reports a second cohort opened Oct 2, 2026 and about US$7.5M in total credits). Extension of Cloudflare for Startups to non-profits was first announced Sep 22, 2025. — [Impact $100M post](https://blog.cloudflare.com/100-million-donations/), [Birthday Week 2025 wrap-up](https://blog.cloudflare.com/birthday-week-2025-wrap-up/), [secondary: Ecosistema Startup](https://ecosistemastartup.com/cloudflare-reparte-us75m-en-creditos-a-30-ongs-asi-construyen-con-ia/)
- **Workers Launchpad** (not a Cloudflare grant): launched Sep 2022 with up to $1.25B from 26 VC partners, later described as over $2B; Cloudflare says it provides no funding itself; the English program page now advertises Cohort #7 applications (search-summary; the page returned 403 to fetch, and a Thai-locale copy that did load looks stale: it links an older cohort's Demo Day, says partners will help fund more than $2 billion, and lists no credits or eligibility); the blog tag lists Cohort #6 (Sep 22, 2025), and eligible startups founded within five years and funded up to Series B may be auto-upgraded to the Startup Plan for a year. — [Launchpad blog tag](https://blog.cloudflare.com/tag/workers-launchpad/), [launch post](https://blog.cloudflare.com/workers-launchpad/), [Launchpad page](https://www.cloudflare.com/lp/workers-launchpad)
- **Cloudflare for Students** (TRIAL/CREDITS): U.S. students, at least 18, with a verified .edu address and enrollment in an eligible program; one year of Workers Paid with the $5/month base fee waived; included allotments listed as 500 Worker scripts, 10 million requests/month, 20 million logs/month, up to 30 s CPU per request, 6,000 build minutes/month, 6 concurrent build slots and extra KV storage; overage is billed at normal rates; redeem by setting the billing email to the .edu address and adding Workers Paid; a valid credit card must be on file; after 12 months the account reverts to Workers Free with no charge unless you upgrade. — [Cloudflare for Students](https://www.cloudflare.com/students/), [launch post](https://blog.cloudflare.com/workers-for-students)
- **Project Alexandria** (PROGRAM; open source): recurring annual credits for open-source projects that use a recognized OSS licence and operate on a non-profit basis and/or align with the project mission; support can include Pro/Business/Enterprise plan upgrades, higher Workers and Pages request limits, more R2 storage, expanded Zero Trust (including Remote Browser Isolation), and a Discord channel; no dollar amounts or renewal terms stated; small projects are told they can stay inside free tiers; apply through cloudflare.com/lp/project-alexandria; announced Sep 27, 2024, page last modified Jul 15, 2026. The landing page states the non-profit rule more strictly than the blog (search-summary). — [Alexandria blog](https://blog.cloudflare.com/expanding-our-support-for-oss-projects-with-project-alexandria/), [Alexandria page](https://www.cloudflare.com/lp/project-alexandria)
- The docs "Sponsorships" page lists sponsored open-source projects (for example Astro, Vite, Node.js, React, Express) but states no terms or application process. — [Sponsorships docs](https://developers.cloudflare.com/sponsorships/)
- **Community programs** (Aug 7, 2026): Cloudflare Ambassadors (up to two years; credits, marketing assets and technical resources for community events; applications closed Sep 6, selections by Oct 5) and Community Engineers (grants from an additional $1M fund over two years for contributors to projects such as Astro, Agents SDK, EmDash, Hono and Vinext; applications open later), at cloudflare.com/community; the post does not mention free plans. — [Community program refresh](https://blog.cloudflare.com/community-program-refresh/)
- Startup hubs and events: free hubs for Workers Launchpad and Cloudflare for Startups participants in San Francisco, Austin, London and Lisbon announced Sep 22, 2025 for 2026; "The Cold Start" is a live pitch event for five early-stage companies at Cloudflare Connect (Birthday Week 2026); an Artifacts "build the next Git platform" competition accepted submissions until Oct 14, 2026. — [Launchpad blog tag](https://blog.cloudflare.com/tag/workers-launchpad/), [Birthday Week 2026 wrap-up](https://blog.cloudflare.com/birthday-week-2026-wrap-up/), [Artifacts changelog](https://developers.cloudflare.com/changelog/post/2026-10-01-artifacts-open-beta/)

### Inferences
- A solo developer building a website + app qualifies most plausibly for Cloudflare for Startups Tier 3 (if incorporated, for-profit and with a company-domain email) or, if a U.S. .edu student, for the Students offer (which still needs a card on file and bills overage); personal blogs, agencies and consultancies are explicitly excluded from Startups.
- The Students and Startups offers are credit/waiver programs layered on paid plans, so they change what is affordable but not what is "free-forever".

### Gaps
- Primary text for the Workers Launchpad page and Project Safekeeping page (both returned 403 to fetch) and for a live Cybersafe Schools program page (404): claims above rest on the Cloudflare blog or search summaries.
- Exact Alexandria credit amounts, any Fair Shot application route, Pangea's current intake status, and the official nonprofit-startup-program page (only the Impact post and a secondary article were found).
- Whether Students overage can be capped (billing caps are only slated for "early availability" in Q4 2026; see cross-cutting rules).

## Cross-cutting rules (zone, payment method, paid plan, overage, terms, beta status)

### Takeaway
Free-account rules: up to 5 Free accounts per user (7-day-old user account), Cloudflare API limit 1,200 requests per 5 minutes per user, and per-product Free caps. Most developer-platform products are usable without a domain; zone-level products (DNS, CDN, WAF, Web3, Client-side security, Email Routing, DMARC, Google tag gateway) need a domain added to Cloudflare. Overage splits into hard stops (Workers, KV, D1, Durable Objects, Browser Run, Observability ingestion, Zaraz unless usage billing is enabled, Images transformations) and automatic billing (R2, Logpush, Web3 gateways, AI Search from Nov 1, 2026, Basin Catalog/Pipelines). A payment method is required for the Students program, Registrar, anything on Workers Paid, and (per sibling notes) Zero Trust onboarding and Basin Catalog/SQL; budget alerts are informational and hard spending caps are only slated for early availability in Q4 2026. Free/Pro/Business zones may not use the CDN to serve video or a disproportionate share of large non-HTML files without paid services.

## Recent changes in 2025-2026 (additions, removals and superseded limits)

### Takeaway
2025-2026 widened free access more than it narrowed it: Durable Objects and Hyperdrive reached Workers Free (Apr 2025), Queues reached Workers Free (Feb 2026), Logpush moved from Enterprise to all plans with 25 GB included (Sep 30, 2026), extra Free accounts became self-serve (Aug-Sep 2026), AI bot policies and more frequent Security Insights scans reached Free, and Observability moved to a unified Free allowance (0.5 GB/day, 7-day retention). No outright removal of a Free allowance was found, but several free-in-beta products started billing (R2 Data Catalog and Pipelines Aug 3, 2026; AI Search Nov 1, 2026; Artifacts Oct 14, 2026) and some limits were superseded (startup credit tiers, Free log limits, DNS record quota).

### Inferences
- Direction of travel: Cloudflare is moving more products from "free while in beta" to metered billing with a small monthly free tier (AI Search, Basin, Logpush, Observability), so a free-only build should budget for those free tiers being fixed monthly or daily amounts rather than open-ended.
- No Free-plan allowance for Workers, KV, D1, R2, Workers AI or Durable Objects was reduced in the sources read; the only Free-tier reductions found are the logging limits and startup-credit-tier changes above.
