## 1. Workers AI: free Neurons, reset, behavior at limit, what the allowance buys, catalog, LoRA, batch, OpenAI endpoints, partner models, playground

### Takeaway
Workers AI is GA and gives every account **10,000 Neurons/day free forever** (resets 00:00 UTC; on Workers Free, going over makes calls fail with HTTP 429 / error 3036, there is no auto-billing). Since 2026-07-28 the most expensive frontier models are paid-only (7 listed on the pricing page as of 2026-10-09). With the cheapest current small LLMs the allowance buys roughly 700-2,600 short chat completions/day (my arithmetic from the published per-model Neuron rates; see Inferences), ~3,300 500-token embedding chunks/day on bge-base, ~170 FLUX-schnell 1024x1024 images/day, ~4 hours of Whisper audio/day.

### Cited Findings

**Allowance, reset, exhaustion, prerequisites** (pricing page last updated 2026-10-09)
- [FREE-FOREVER, GA] Free allocation is 10,000 Neurons per day at no charge, on both Workers Free and Workers Paid; Workers AI is "included in both the Free and Paid Workers plans" — [Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/)
- Beyond the allocation: Workers Free = "N/A - Upgrade to Workers Paid" (no overage possible); Workers Paid = $0.011 per 1,000 Neurons — [Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/)
- Limits reset daily at 00:00 UTC; once a limit is exceeded "further operations will fail with an error" — [Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/)
- The exhaustion error is internal code 3036, HTTP 429 "Account limited" (message: daily free allocation of 10,000 neurons used up, upgrade to Workers Paid to continue). Other relevant codes: 3040/429 Out of capacity (also returned when `rejectIfBusy` rejects); 5035/403 "Model requires Workers Paid plan"; 3006/413 request too large; 3007/408 timeout; 5016/403 Llama 3.2 model-terms agreement not accepted; 5005/405 model does not support LoRA — [Workers AI errors](https://developers.cloudflare.com/workers-ai/platform/errors/)
- Usage is monitored in the Workers AI dashboard (dash.cloudflare.com -> AI -> Workers AI) — [Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/)
- Callable from Workers, Pages, or anywhere via the Cloudflare REST API (so a Worker is not strictly required); Workers AI is declared GA — [Workers AI overview](https://developers.cloudflare.com/workers-ai/), [Workers AI limits](https://developers.cloudflare.com/workers-ai/platform/limits/)
- Neurons are Cloudflare's unit for GPU compute; since Sept 2024 pricing is shown per model unit (tokens, tiles, audio minutes) but "still billing in neurons in the back end"; the Tokens and Neurons columns are equivalent — [Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/), [Workers AI changelog 2024-09-26](https://developers.cloudflare.com/workers-ai/changelog/)
- Prerequisites stated in docs: a Cloudflare account; an AI binding (`env.AI`) in a Worker/Pages Function, or an API token with Workers AI permission for REST (Account ID + token). Docs reviewed do not say a payment method is required for Workers Free — [Workers AI REST/Markdown prerequisites](https://developers.cloudflare.com/workers-ai/features/markdown-conversion/usage/rest-api/), [Workers AI overview](https://developers.cloudflare.com/workers-ai/)

**Features**
- OpenAI-compatible endpoints: `/v1/chat/completions` and `/v1/embeddings` (swap baseURL to `https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/v1`); `/v1/responses` only for gpt-oss-120b/20b and non-streaming only; also works through AI Gateway; `options.rejectIfBusy` fails fast instead of queueing — [OpenAI compatibility](https://developers.cloudflare.com/workers-ai/configuration/open-ai-compatibility/), [Reject busy requests](https://developers.cloudflare.com/workers-ai/features/reject-if-busy/)

## 2. AI Gateway: free features, free log storage, paid parts

### Takeaway
AI Gateway is available on all plans and its core features (dashboard analytics, caching, rate limiting) are explicitly free; the docs also describe DLP scanning as free and User Insights as "no additional cost", and list dynamic routing, spend limits, Auto Router, retries/fallbacks, custom costs and a WebSockets API with no separate fee on the pricing page. Free plan = 10 gateways. Guardrails are free to switch on but run Llama Guard on Workers AI, so they burn the 10,000 Neurons/day. Logs changed on 2026-09-24: gateways created before that date keep Legacy Logs (Free = 100,000 logs total across all gateways); accounts whose first gateway is created on/after that date follow Workers Logs terms (Free = 200,000 log events/day, 3-day retention). Paid or credit-based: Unified Billing credits (5% fee), Logpush (Workers Paid), Web Search API (open beta, per-search billing), x402 Machine Payments (beta, US + card on file). Evaluations are deprecated for new accounts.

### Cited Findings

**Plan, status, prerequisites**

## 4. AI Search (formerly AutoRAG): free status, limits, consumed products

### Takeaway

## 5. Agents SDK, McpAgent / remote MCP on Workers, workers-oauth-provider, Code Mode, templates, Cloudflare-hosted MCP servers

### Takeaway
There is no separate Agents SDK price: the SDK is code you deploy to Workers, each Agent is a SQLite-backed Durable Object, and limits are inherited from Workers/Durable Objects (Workers Free supports SQLite-backed Durable Objects; the chat-agent example says a free-tier account works). ### Inferences

## 7. Markdown conversion (env.AI.toMarkdown / REST)

### Takeaway
[FREE for most formats; GA] `toMarkdown` is free for most format conversions; image conversion uses Workers AI models (object detection + a vision LLM) which can consume the Workers AI free allocation and incur cost beyond it. No file-size or rate limit is documented on the Markdown Conversion pages.

### Cited Findings
- Pricing: free for most formats; image conversion calls Workers AI models and "may incur additional costs if it exceeds the Workers AI free allocation" — [Markdown Conversion](https://developers.cloudflare.com/workers-ai/features/markdown-conversion/)
- Image path: GIF -> first frame only; SVG rasterized to PNG; images larger than 1280x720 are resized; `@cf/facebook/detr-resnet-50` object detection, then `@cf/google/gemma-4-26b-a4b-it` (9,091/27,273 neurons per M in/out) writes the description — [How it works](https://developers.cloudflare.com/workers-ai/features/markdown-conversion/how-it-works/), [Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/)
- Supported formats: PDF (.pdf); images (.jpeg .jpg .png .webp .svg .gif .bmp); HTML (.html .htm); XML (.xml); Microsoft Office (.xlsx .xlsm .xlsb .xls .et .docx); Open Document (.ods .odt); CSV (.csv); Apple Numbers (.numbers) — [Supported formats](https://developers.cloudflare.com/workers-ai/features/markdown-conversion/supported-formats/)
- Interfaces: `env.AI.toMarkdown([...{name, blob}])` binding, or REST `POST https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/tomarkdown` (multipart `files`, optional `conversionOptions`) needing a Workers AI API token; each result returns `format` ("markdown" or "error"), token estimate (`tokens`) and data — [Binding usage](https://developers.cloudflare.com/workers-ai/features/markdown-conversion/usage/binding/), [REST usage](https://developers.cloudflare.com/workers-ai/features/markdown-conversion/usage/rest-api/)
- 2026-07-13: new `output.format` option (`text` returns plain text with Markdown syntax removed; default `markdown`) — [Cloudflare Workers AI changelog](https://developers.cloudflare.com/changelog/product/workers-ai/)
- Related: Browser Run `/markdown` endpoint for dynamic pages, and "Markdown for Agents" (zone content negotiation; out of my scope, belongs to the zone/security researchers) — [Markdown Conversion](https://developers.cloudflare.com/workers-ai/features/markdown-conversion/)
- Consumers: the Agents SDK `web_fetch` tool (2026-10-12) converts HTML/PDF/Office documents through Workers AI Markdown Conversion and requires an `ai` binding; AI Search converts non-text files with it during sync and gained GIF/BMP image support on 2026-07-08 — [web_fetch tool](https://developers.cloudflare.com/agents/tools/web-fetch/), [AI Search release notes](https://developers.cloudflare.com/ai-search/platform/release-note/)

### Inferences
- Use it for PDFs/Office/HTML ingestion into Vectorize at zero Neuron cost; avoid image inputs on Free if Neurons are tight.
- Website+app idea: user uploads a PDF/DOCX -> Worker `toMarkdown` -> chunk -> bge embeddings -> Vectorize.

### Gaps
- No documented per-file size limit, per-request file count or rate limit on these pages (AI Search separately caps PDFs at 4 MiB, 10 MiB with OCR).
- Exact Neuron cost of one image conversion not published (only underlying model rates).
